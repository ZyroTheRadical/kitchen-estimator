GUIDE

Kitchen measurement guide

Use a tape measure and note the lengths where you plan to add cabinets or countertops.

  1. Measure each wall run. Measure along the wall from one end of the planned cabinet or counter run to the other. Measure runs separately; don’t use the room perimeter.
  2. Add the run lengths. Enter the total in linear feet. Convert inches to feet by dividing by 12.
  3. Count extras separately. Count each planned corner cabinet once (3–5 units), and note the number of sinks (1–2 if applicable).

Example: 10 ft + 8 ft = 18 linear ft. This estimator accepts 3–50 linear feet.
